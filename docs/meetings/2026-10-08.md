## 3. 논의 내용과 결정 사항 (이유 포함)
[논의 내용]

- 소규모 프로젝트의 짧은 개발 기간과 가볍고 빠른 데이터 관리 방식을 고려해 인증 체계와 데이터베이스 구조를 검토함.

[결정 사항]

- 미니 프로젝트의 짧은 개발 기간을 고려해, 구조가 단순하고 구현이 직관적인 **세션 기반 인증 방식**을 채택함.
- 별도의 대형 DB 서버 구축 없이 가볍게 파일 형태로 관리하기 위해, **데이터베이스로 SQLite**를 사용하기로함.
- 페이지가 새로고침되거나 사용자가 조작할 때 발생하는 상태 초기화를 방지하고 로그인 정보를 유지하기 위해, 로그인 상태 관리에 **Streamlit의 `st.session_state`**를 활용하기로 함.
