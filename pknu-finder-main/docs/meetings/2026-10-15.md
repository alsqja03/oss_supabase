## 3. 논의 내용과 결정 사항 (이유 포함)

- `good first issue` 라벨 이슈 2개 이상 등록 — 초보 기여자가 쉽게 참여할 수 있도록 README 보완 등을 위한 **문서 수정**, **간단한 버그 수정**을 라벨 이슈로 선정함.
- 홈페이지 UI 기본 틀에 대한 논의 — 화면 구성을 미리 시각화하여 구현 방향을 통일하기 위해 Figma로 작성함.

  → Figma 링크: [OSS 오픈소스 소프트웨어](https://www.figma.com/design/7vA9JaG9AGwCInCfUqMYNx/OSS-%EC%98%A4%ED%94%88%EC%86%8C%EC%8A%A4%EC%86%8C%ED%94%84%ED%8A%B8%EC%9B%A8%EC%96%B4?node-id=0-1&t=IcxpdEOXdnZhEWzE-1)

- 메인 페이지에 환영 문구 표시 및 로그아웃 버튼을 마이페이지에 배치하기로 결정 — 로그인한 사용자의 상태를 메인 화면에서 명확하게 안내하고, 마이페이지에서 계정 관련 기능을 모아 제공할 수 있도록 하기 위해
- 검색 필터를 카테고리, 장소, 시작 날짜, 종료 날짜로 구분하기로 결정 — 사용자가 원하는 분실물·습득물을 조건별로 쉽게 검색할 수 있도록 함.
